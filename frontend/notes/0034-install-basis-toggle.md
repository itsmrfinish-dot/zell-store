# ميزة إضافة سعر التركيب الفني (أساس متر مربع)

## الملخص
إضافة إعداد في لوحة التحكم لتحديد سعر التركيب الفني بالمتر المربع.

رسوم التركيب الفني تُحسب دائماً بناءً على: **الطول × عرض الرول × سعر المتر المربع**

## التغييرات

### 1. Database (Migration 0034)
- إضافة عمود واحد فقط إلى جدول `store_settings`:
  - `install_price_per_sqm` (DECIMAL): السعر بالمتر المربع (افتراضي: 100 جنيه)
- دالة جديدة `calculate_install_fee()` لحساب الرسوم بناءً على المساحة
- إضافة عمود إلى `settings_audit` للتدقيق

### 2. Backend Function
**ملف**: `/backend/installation/calculateInstallationFee.ts`

تقبل:
```typescript
{
  productIds: number[],
  lengths: number[],
  rollWidths: number[],
  pricePerSqm: number
}
```

تعيد:
```typescript
{
  totalFee: number,
  unit: 'ج.م/متر مربع',
  details: Array<{
    productId: number,
    length: number,
    rollWidth: number,
    area: number,
    fee: number
  }>
}
```

**الحساب**:
- `totalFee = Σ(length × rollWidth) × pricePerSqm`

**أمثلة**:
- 3 متر × 0.5 متر = 1.5 متر مربع × 100 ج.م/متر² = 150 ج.م
- 50 سم (0.5 م) × 3 متر = 1.5 متر مربع × 100 ج.م/متر² = 150 ج.م

### 3. Frontend Components

#### InstallationPriceEditor (سابقاً InstallationBasisEditor)
محرر إعدادات سعر التركيب في اللوحة:
- إدخال السعر بالمتر المربع فقط
- الافتراضي: 100 جنيه
- توضيح للحساب بأمثلة

#### InstallationFeeDisplay
عرض رسوم التركيب:
- يعرض "ج.م/متر مربع" فقط
- يحسب المساحة (طول × عرض رول)
- يعرض التقدير بناءً على السعر المحدد

### 4. اختبارات
تغطي:
- حالات حساب مساحة واحدة ومتعددة
- المثال 50 سم × 3 متر = 1.5 متر مربع
- معالجة الأخطاء (بيانات فارغة، أطوال سالبة، عروض سالبة)
- دقة التقريب (حتى 2 منزلة عشرية)

## ملاحظات على الكود

### صندوق المعاينة
لا يتعارض مع أساس الحساب - الحساب دائماً بالمتر المربع.

### الفيلم (Film Product)
يبقى يُباع بالمتر الطولي فقط - هذا التغيير يؤثر على رسوم التركيب فقط.
